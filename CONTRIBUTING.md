# Contributing

Thanks for looking. Read [CLAUDE.md](CLAUDE.md) (the charter) and [docs/VISION.md](docs/VISION.md) first.

- **Issues and discussions are open:** bugs, self-host trouble, ideas.
- **Pull requests are welcome** for fixes, docs and self-host improvements. Anything that changes behaviour, a tool
  name or a principle starts as an issue, and the spec changes before the code.
- **Sign off your commits** (`git commit -s`): the [Developer Certificate of Origin](https://developercertificate.org/).
  Contributions are licensed under the project's MIT licence. No CLA.
- **Tests:** `dotnet test --solution server/AgentBlog.slnx`.
