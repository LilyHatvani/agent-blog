# Telling your agents how the blog sounds

Say once how your blog should sound, and every agent reads it before it writes. When you decide on what an agent asks,
you can tell it why, and send notes that every agent reads from then on.

What you write here is the one text on the blog that agents follow as instructions, because you wrote it. Nothing an
agent writes can change it.

## Write the brief

1. Open the **Account** tab and go to **How this blog sounds**.
2. Fill in what applies. Every field is optional:
   - **Who it's for**: up to 500 characters.
   - **The voice**: up to 2,000 characters.
   - **Never**: what an agent must not do, up to 2,000 characters.
   - **Posts that sound right**: tick up to 3 of your posts. Drafts count; posts in the trash aren't listed.
3. Tap **Save**. It stays off until you change something; **Cancel** puts back what was saved.

"Saved. The next agent session reads it." An agent that is already in a conversation reads the brief the next time it
starts a session.

## Decide on a request, with a reason

An agent asks in the **Inbox** tab when what it wants is above its level: publishing, scheduling, changing a live post,
trashing. Each card has three buttons:

| Button | Note | What happens |
| --- | --- | --- |
| **Approve** | none | the change applies, and the card leaves the Inbox |
| **Ask for changes** | required | nothing applies; the agent is told to change the post and ask again |
| **Decline** | optional | nothing applies; the request is closed |

To ask for changes:

1. Tap **Ask for changes**.
2. Under **What should change?**, write what you want, for example "Cut the intro, say what changed."
3. Tap **Send to the agent**. It stays off while the note is empty.

The agent reads your note on the request, on the post, and when it next starts. When it has made the changes, it asks
again and a new card appears.

To decline, tap **Decline**, write a reason under **Why? (optional, the agent reads it)** or leave it empty, and tap
**Decline** again.

To change the agent's text yourself before approving, see [Editing a post on your phone](editing-on-your-phone.md).

## Send a note to every agent

For what you'd otherwise repeat in every chat ("Every post needs an excerpt").

1. Open the **Agents** tab and find **Tell your agents**.
2. Write the note, up to 2,000 characters.
3. Tap **Send to all agents**.

Every agent reads your 10 newest notes when it starts a session, marked as yours. Your reasons from the Inbox land in
the same list, labelled **On declining**, **Changes asked** or **On approving**, with the post they are about. A note
past the newest 10 shows "no longer sent (older)".

## Retire a note

A note that no longer holds can be retired; it is never deleted.

1. In **Tell your agents**, tap **Retire** on the note.
2. It stops being sent to agents and moves to **Retired notes**. Tap that to see them again.

A retired note can't be brought back or edited. Write a new one instead.

## If something goes wrong

- "Asking for changes needs a note: say what to change." The note was empty.
- "The post changed since the agent asked, so approving won't apply anything." Someone saved a new revision after the
  agent asked. **Approve** is off; decline the request or let the agent ask again.
- "This request is already declined." (or approved, or changes_requested): it was decided elsewhere, for example in
  another tab. Open the Inbox again to see where it stands.
- "An example post isn't one of this blog's (or it's in the trash)." An example post was trashed while you were
  choosing. Untick it and save again.
